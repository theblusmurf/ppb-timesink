# Sleek desktop update

The desktop now uses a slate palette with a teal Start action, rounded settings cards, clearer section headings, larger body text, and more consistent navigation and spacing. Operating mode, recovery, advanced settings, and automatic support have distinct sections. Supported Windows versions also use a dark title bar.

All existing modes, healing thresholds, potion options, and automatic saving remain available. The controls and their existing event handlers are retained. Default and minimum window sizes remain 980 x 700 and 900 x 640.

Validation: Release build, offline policy checks, mode persistence, autosave, invalid-setting protection, and rendered UI checks. Live gameplay is not part of this visual update's validation.
