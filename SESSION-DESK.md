# Session Desk overview

The selected second Overview concept is implemented with the existing graphite/lime theme and navigation.

- Quick fields: operating mode, target name filter and Gamekeeper priority.
- Session totals: net wallet gold and active-hour rate, active farming time and detected kills. Unavailable wallet readings remain unavailable.
- Resource ledger: detected Silvin, Mithril, Iternium, Fehu and Gems, with the existing loot details and reset actions.
- Route snapshot: current-zone saved paths, corridor, anchor area and the accepted player position, plus target-family shortcuts. Missing or stale player readings cannot invent a marker.
- Six accessible collapsed sections: targets/combat, skills/healing, movement/loot, death/client recovery, route/anchor radius and saved routes. Summaries remain visible when collapsed.

Overview and Farming edit the same guarded controls. No new settings format, collector, game access or gameplay behavior is introduced. Three configuration columns become two or one as the window narrows; the ledger and route view stack at narrow widths. Expanded sections remain accessible through scrolling. Main navigation, bottom Start/Stop/Connect actions, overlays and the verified local 3D mapping remain unchanged.

Validation uses the disconnected native application: existing data/persistence/layout checks, Overview/Farming synchronization, target route selection, numeric/slider bindings, working/busy/client-recovery/healer guards, accessible folding, unknown totals and minimum/constrained window bounds. Native screenshots are local diagnostic output, not live gameplay evidence.
