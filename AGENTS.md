# Development workflow

Publish future PoteHunter updates to the private GitHub repository https://github.com/theblusmurf/PoteHunter so progress is tracked. Commit validated changes with clear messages and report the commit or release URL. If publication is blocked, report it as pending.

Preserve existing user settings and backups. Do not commit local runtime state, game data, build outputs, SDK caches, or credentials. Run appropriate offline checks before publication, and distinguish offline validation from live gameplay testing.
