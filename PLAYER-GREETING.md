# Nearby player greeting

PoteHunter can greet recognized players who enter the configured 25 map-unit radius. The greeting is enabled by default and appears in **Advanced settings** as “Say hello to recognized players within 25 map units.”

Each recognized player is greeted once per run, using the in-game chat message `Hello!`. The identity cache resets when healer or combat mode starts and when the run ends, so a player can be greeted again in a later run.
